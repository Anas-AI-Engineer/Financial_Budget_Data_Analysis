# Financial Budget Analysis 📊

## About the Project
This is a Python-based Financial Budget Analysis project built using NumPy and Pandas. It analyzes financial data to understand spending habits, compare budgets with actual expenses, and explore income and expense patterns.

## Features
- General Expense Statistics
- Category-Wise Expense Analysis
- Top 10 Highest Expenses
- Budget Comparison
- Monthly Expense Analysis
- Income vs Expense Analysis
- Payment Method Analysis
- Needs, Wants, and Savings Analysis
- Essential vs Non-Essential Expense Analysis
- Income and Expense Correlation
- Search Expenses by Category
- Interactive Menu-Based System

## Technologies Used
- Python
- NumPy
- Pandas
- CSV Dataset

## How to Run
1. Clone or download this repository.
2. Install the required libraries:

   ```bash
   pip install numpy pandas
   ```

3. Make sure `Financial_Budget_Analysis.csv` is in the same folder as the Python script.
4. Run the Python file:

   ```bash
   python main.py
   ```

   Replace `main.py` with your actual Python filename if it's different.
